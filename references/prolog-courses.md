# Prolog teaching material: survey of online resources

Reference survey for designing an introductory **SWI-Prolog** course, taught in Spanish, for second-year university students who know only a little imperative C. The course will likely be built as **self-paced SWISH notebooks**, so the **SWISH** column marks the resources that run code inside the page.

- **Date checked:** 2026-09-18. Each "verified" URL returned HTTP 200 on that date (with `curl`, WebFetch, or the GitHub/YouTube APIs), and its content was checked to match the description.
- **Column key:**
  - **SWI:** uses SWI-Prolog specifically (✔), mostly works in SWI (≈), or uses another system (✘, with the system named).
  - **SWISH:** code runs in the page or the resource is a SWISH notebook (🟢), code links to SWISH (🟡), or no SWISH.
  - **Sol.:** the exercises come with solutions.
  - **Lvl:** B = beginner, I = intermediate, A = advanced.
- Companion file: [`ejercicios/newthinktank.md`](ejercicios/newthinktank.md) has 19 exercise candidates taken from Derek Banas's video, tested in SWI-Prolog 9.2.9.

---

## Top picks for our audience

1. **[Learn Prolog Now! (SWISH edition)](https://lpn.swi-prolog.org/)** (Blackburn, Bos, Striegnitz) 🟢. This is the standard first-course text and the closest existing model of a "Prolog course in SWISH". Its 12 chapters each have exercises and a practical session. It needs small updates for SWI-Prolog 7+ (the site itself says so), and it is in English.
2. **[Programación lógica con Prolog](https://jaalonso.github.io/materias/PLconProlog/)** + **[Ejercicios-Prolog](https://github.com/jaalonso/Ejercicios-Prolog)** (José A. Alonso, U. Sevilla) 🟡. This is the best Spanish-language set of notes: 16 topics, SWI-Prolog, CC BY-NC-SA. The exercise solutions are published as SWISH programs (`PLP_ejercicios-tema-N.pl`), under GPL-3.0. Topics 1–5 map directly onto an introductory course.
3. **[UTN FRBA – Paradigmas de Programación, apuntes del paradigma lógico](https://www.pdep.com.ar/material/apuntes)** 🟡. These are Spanish notes from our own university: six modules (predicates and closed-world assumption, variables and rules, compound individuals, higher-order predicates, recursion, design) plus PlUnit testing, all with SWI-Prolog. They match the vocabulary our students will meet in later courses.
4. **[Simply Logical (online edition)](https://book.simply-logical.space/)** (Peter Flach) 🟢. This is a complete Jupyter-Book textbook with embedded SWISH code blocks, under CC BY-NC-SA 4.0. It is the best technical model for a notebook-based course. It leans toward AI and theory, so it suits instructors or selected chapters (Part I).
5. **[Derek Banas – Learn Prolog in One Video](https://www.newthinktank.com/2015/08/learn-prolog-one-video/)** ([YouTube](https://www.youtube.com/watch?v=SykxWpFwMGs), 1 h 04 min). This is the quick one-hour overview; the user describes it as "a great course, to be learnt in 1 hour". The full code is on the page, with chapter timestamps. It was probably recorded with GNU Prolog, so it shows `yes`/`no` answers and GNU-style traces. Several snippets need fixes in SWI; see [`ejercicios/newthinktank.md`](ejercicios/newthinktank.md).
6. **[The Power of Prolog](https://www.metalevel.at/prolog)** (Markus Triska), with [45 videos](https://www.metalevel.at/prolog/videos/). This is the modern, "pure/declarative" view of Prolog. It is excellent for the instructor's own stance (termination, `clpfd`/`clpz`, avoiding impure constructs). It is too dense as the students' main text.
7. **[SWISH notebook examples](https://swish.swi-prolog.org/example/prolog_tutorials.swinb)** and **[Brandon Bennett's Prolog Intro Exercise Notebook](https://swish.swi-prolog.org/p/BB_Prolog_Intro.swinb)** 🟢. These are concrete models of a notebook exercise sheet. Bennett's notebook (Leeds, 2024-11-11, 65 cells) covers a family database and lists, with tasks built in.
8. **[Using SWISH to realise interactive web-based tutorials for logic-based languages](https://arxiv.org/abs/1808.08042)** (Wielemaker, Riguzzi, Kowalski et al., TPLP 2019). This is the design paper for exactly what we plan to build: SWISH notebooks as course material, with classroom experience from Ferrara and Imperial.
9. **[Exercism Prolog track](https://exercism.org/tracks/prolog)** and **[P-99: Ninety-Nine Prolog Problems](https://www.ic.unicamp.br/~meidanis/courses/mc336/2009s2/prolog/problemas/)**. These are graded practice sets to mine for exercises: Exercism has autograded SWI tests and optional mentoring, and P-99 is organised by difficulty.
