# Licencia

El texto y los ejemplos de este curso se publican bajo la licencia MIT, cuyo
texto completo está en el archivo `LICENSE` del repositorio.

## Lo que este curso cita

Este curso se apoya en libros, cursos y colecciones de ejercicios de otras
personas. Nada de eso se copia acá: se lo cita, se lo enlaza y, cuando hace
falta, se reescribe el enunciado con nuestras palabras y nuestros datos.

Varias de esas fuentes tienen licencias que no permiten el uso comercial ni la
redistribución, y este curso sí lo permite. Mantener la distancia no es una
formalidad: es lo que hace que la licencia MIT de arriba sea cierta.
